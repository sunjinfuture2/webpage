# SUNJIN Schedule

판교 AIDC 마스터스케줄을 읽고 편집하는 독립 일정관리 앱입니다. 기존 홈페이지와 별도로 실행합니다.

## 시작하기

Node.js 22.12 이상과 npm이 필요합니다.

```sh
cd apps/scheduler
npm ci
npm run dev
```

개발 서버 기본 포트는 5173입니다. 처음 열면 사용자가 일정 파일을 선택합니다. 지원 파일은 판교 AIDC 마스터스케줄 형식의 XLSX, 일정 원본 JSON, 앱에서 내보낸 작업공간 JSON/XLSX입니다. 일반적인 임의 엑셀 양식을 자동으로 변환하는 기능은 제공하지 않습니다.

파일은 서버로 전송하지 않으며 브라우저에서 분석·계산합니다. 편집 결과는 이 기기의 IndexedDB에 자동 저장되고 다음 방문에 복원됩니다. 다른 주소나 기기에서는 JSON 백업을 가져와 이어서 사용합니다.

원본 문서, 업무 데이터, 원본이 보이는 스크린샷은 공개 저장소와 빌드에 포함하지 않습니다. 예시 화면을 만들기 위한 가짜 사업 데이터를 기본 일정으로 표시하지 않습니다.

## 제공 기능

- 통합 마스터 일정: 단계별 기간·최소 여유·주요 승인을 먼저 보고, 필요한 단계를 눌러 같은 시간축에 세부 간트를 펼침. 여러 단계를 독립적으로 접고 펼치며 상태를 저장.
- Ctrl/⌘ K 빠른 찾기: 업무번호·이름·담당·화면 검색, 키보드와 터치 조작.
- 업무 옆 연결 아이콘: 바로 연결된 업무부터 선행·후속 전체 경로까지 집중해서 확인.
- 일정 이동 시 업무별 전후 날짜 비교, 미적용 입력을 보호하는 업무 전환, 짧은 상태 피드백과 동작 줄이기 지원.

- 단계별 WBS·가상화 간트, 축척·접기·참조계획·연결선 표시, 그리드 너비 조절.
- 막대의 시작·완료 끝점을 다른 업무로 끌어 FS/SS/FF/SF 생성, 선 선택 편집·삭제.
- 관계를 ‘앞 업무가 끝나면 시작’처럼 설명하고, 추가 대기·앞당김을 빠르게 선택. 키보드는 끝점을 차례로 눌러 같은 기능을 사용.
- 선행/후행 경로와 전체 관계 목록으로 화면 밖 업무까지 탐색.
- 업무 관계도: 교차를 줄이는 좌우 배치, 카드 사이 전용 통로와 분리된 연결점, 선택 업무·관계 강조. 배치를 유지하면서 탐색하고 관계를 바로 추가·수정.
- 프로젝트 연결: 엑셀/백업/저장된 작업공간 사본을 추가하고, 프로젝트 사이 관계·지연·영향을 함께 계산.
- 시나리오별 연결 프로젝트·관계를 독립 보존하고, 변경 전후 프로젝트 완료일과 업무별 변동을 미리 확인.
- 업무 추가·수정·삭제, 담당·진척·실제일·잔여기간 편집과 입력 검증.
- 간트 막대 이동·기간 조절, 영향 미리보기 후 적용.
- FS/SS/FF/SF 관계, 양수·음수 간격, 순환 관계 검사, 일정 자동 재계산.
- 월·주 캘린더와 날짜별 업무 목록, 업무 상세 패널.
- 조달 PO 지연·납기·기산조건 편집, 승인게이트와 근거 대장 조회.
- 시나리오 복제·비교, 운영개시까지의 대표 결정 경로 조회.
- 로컬 작업공간 선택, 탭 간 저장 충돌 감지, 실행취소·다시실행.
- 전체 JSON 백업/복원, XLSX 가져오기·내보내기, 업무·관계 CSV 내보내기.

계산은 달력일 기준입니다. 일반 업무는 시작·완료일을 포함하고 마일스톤은 0일입니다. 실제일은 고정하며 관계 위반을 표시합니다. 원본 참조계획과 편집한 관리일·예상일을 구분하고, 미입력 담당·진척·납기는 공란으로 보존합니다. 원본 상태일을 오늘로 자동 변경하지 않습니다.

승인게이트와 확약 정보는 실제 승인·공급 확약으로 간주하지 않습니다. 표시하는 운영개시 일자는 입력한 조건에 따른 예상입니다.

## 마스터 일정 디자인

마스터 일정과 캘린더는 제공된 WorkSpace 캘린더의 흰 여백·검정 월 제목·얇은 가로선·파스텔 프로젝트 칩을 따릅니다. 캘린더의 기간 업무는 주별로 이어지는 막대로 표시하며, 가려진 업무는 날짜별 목록에서 확인합니다. 연결 프로젝트가 있으면 실제 프로젝트 칩으로 함께 표시하고 필터링합니다.

`index.html?view=calendar` 링크로 캘린더를 바로 열 수 있습니다. 이미 저장된 일정이 있으면 그대로 사용하고, 처음 방문하면 기존과 같이 파일을 선택합니다. 명시적인 프로젝트 hash 경로는 해당 경로의 보기를 우선합니다. 화면을 연 뒤에는 주소의 현재 보기로 상태를 유지합니다.

화면 설계 기준은 [마스터 일정 디자인](docs/master-schedule-design.md)을 참고하세요.

`index.html?view=gantt`로 통합 마스터 일정을 엽니다. 이전 `?view=overview` 링크와 백업도 같은 화면으로 연결됩니다. 새 작업공간은 단계를 접은 상태와 전체 기간 맞춤으로 시작합니다. 단계 이름이나 요약 막대를 누르면 해당 단계만 펼쳐집니다. 자세한 편집에는 일·주 단위 축척을 사용하고, 연결 집중 보기를 닫으면 기존 축척을 복원합니다.

최신 화면 구조·연결선 배치 알고리즘·개발 프롬프트는 [통합 일정과 관계도 설계](docs/master-outline-network-layout.ko.md)를 참고하세요. PDF와 Linear·OmniPlan의 사용 방식에서 적용한 구조, 확인한 공식 출처와 조사 범위는 [탐색·조작 설계 기록](docs/navigation-and-interaction.ko.md)에 정리했습니다.

## 프로젝트를 연결하기

1. 왼쪽 **프로젝트 연결**을 엽니다.
2. **프로젝트 파일 추가** 또는 **저장된 프로젝트**로 연결할 계획을 추가합니다.
3. **프로젝트 연결** 버튼에서 선행·후행 프로젝트와 업무, FS/SS/FF/SF와 달력일 간격을 정합니다.
4. 영향 미리보기의 날짜·확인사항을 보고 **연결 변경 적용**을 누릅니다.
5. 프로젝트 카드를 선택해 해당 업무의 지연을 조정하거나, 현재 프로젝트의 업무 상세에서 일정을 수정합니다.

추가한 프로젝트는 현재 작업공간이 소유하는 독립 사본입니다. 다른 작업공간·기기와 자동 동기화하지 않습니다. 현재 시나리오를 복제하면 연결 계획도 함께 복제하며, 다른 시나리오의 입력은 보존합니다. 전체 JSON 백업과 XLSX 복원 데이터에 연결 프로젝트를 포함합니다. CSV 관계표는 현재 프로젝트 내부 관계입니다.

업무 관계도는 기본적으로 선택 업무와 한 단계의 연결을 표시합니다. 업무 카드를 누르면 위치를 유지하며 관련 선을 강조하고, **이 업무 중심으로**를 눌러 범위를 바꿉니다. **관계 수정**은 간트와 같은 검증·저장·실행취소 경로를 사용합니다. 표시 한도는 업무 120개·관계 600개이며 숨긴 수를 안내합니다. 계산에는 모든 관계를 유지합니다. 간트 연결선도 화면·표시 범위에 따라 줄여 그리며 관계 목록에서 전체를 조회할 수 있습니다.

공식 출처와 계산 경계는 [연결 일정 설계](docs/connected-schedule.md), 후속 검증 지침은 [개발 프롬프트](docs/implementation-prompt.ko.md)를 참고하세요.

## 빌드와 미리보기

```sh
npm run build
npm run preview
```

정적 배포 파일은 `dist/`에 생성됩니다. 상대 자산 경로와 hash routing을 사용하여 하위 경로에서도 실행할 수 있습니다. HTTPS 또는 localhost의 HTTP 서버에서 여세요.

저장소에 포함할 정적 미리보기를 갱신하려면 다음 명령을 실행합니다.

```sh
npm run prepare:preview
```

결과는 저장소의 `previews/scheduler/`입니다. 이 명령은 문서·데이터 JSON·검증 스크린샷이 빌드에 포함되면 중단합니다. GitHub Pages 설정 변경이나 기존 홈페이지 수정은 수행하지 않습니다.

## 검증

```sh
npm test
npm run build
```

공개 테스트는 합성 데이터로 관계별 일정 계산, 지연 전파, 순환 거부, 실제일 유지, 월말·윤년, JSON/XLSX 왕복 복원, CSV 공란·0 처리와 5,000업무/15,000관계 계산 성능을 검증합니다. 가변 높이 일정 행의 좌표, 관계도 교차 감소·카드 관통 방지·병렬 관계 구분·가까운 업무 우선 표시도 검증합니다. 제공 문서에 대한 비공개 수용 검증 자료는 저장소에 올리지 않습니다.

## 현재 구현 범위

단일 사용자 로컬 앱의 첫 릴리스입니다. MS Project의 모든 기능이 구현된 상태는 아닙니다. 영업일·자원 달력, 자원 배정/평준화, 원가/EV, 승인 기준선, 반복/분할 작업, Project XML/MPP, 서버 로그인·공동 편집·기기 간 동기화, 홈페이지 통합은 후속 범위입니다. CSV는 내보내기만 지원합니다.

XLSX 내보내기는 업무 시트와 복원용 숨김 JSON을 포함합니다. 원본 엑셀의 표시용 간트 서식과 수식 배치를 복제하지 않습니다. 수식 실행 대신 원본에 저장된 결과를 읽습니다.

실행취소는 세션·시나리오별 최근 40개 변경을 보존하며, 재시작 후 편집 결과와 최근 200개 명령 이력을 복원합니다. 브라우저 데이터를 삭제하기 전에는 JSON 백업을 내보내세요. 연결의 기준이 되는 조달·지원·운영개시 업무는 삭제를 보호합니다.

## 디자인과 라이선스

SUNJIN의 주황색 `#F47920`, 밝은 중립색 배경, 간결한 탐색과 우측 상세 패널을 사용합니다. Pretendard 공식 배포 글꼴을 자체 호스팅합니다. 글꼴·주요 라이브러리의 라이선스 원문은 `public/licenses/`와 빌드의 `licenses/`에 포함합니다.
