# 본문 편집기 (schema v2)

액션아이템 · 리서치 · 미팅 · 자료실 글의 본문을 쓰는 블록 편집기. 「AIDC WorkSpace 노션형 본문 편집기 구현 지시서 v1.0 (2026.11.18)」을 기준으로 만들었다.
이 문서는 구조, 저장 형식, 되돌리는 방법, 그리고 지시서 항목별 상태(완료 / 부분 / 미구현 / 차단)를 적는다.

## 구조

- 엔진: Tiptap 3.34 (ProseMirror), 코드 강조 lowlight(highlight.js, BSD-3), 수식 KaTeX, Markdown 읽기 marked, 함께 수정 Yjs. 모두 MIT / BSD, 유료 확장 · 외부 서비스 없음. 번들에 들어간 패키지의 라이선스 전문은 빌드 때 `public/editor.licenses.txt`로 만든다.
- 소스는 `editor/`, 빌드(`build-shared.mjs`)가 esbuild로 `public/editor.js` 하나로 묶고 `editor/editor.css`는 페이지에 넣는다. 앱은 `window.AIDCEditor`만 쓴다.

## 저장 형식

- 본문은 지금처럼 글 레코드의 `body`(HTML 문자열)에 저장한다. v2 본문은 `ed: 2`가 붙고, 편집기가 스키마에서 만들어 낸 HTML만 들어간다(화면 DOM을 그대로 저장하지 않는다). 서버의 `cleanHtml`, 검색, 목록 요약, 첨부 목록, 멘션 알림은 그대로 동작한다.
- 블록마다 `data-id`(영구 ID). 이동 · 전환은 ID를 유지하고 복제 · 붙여넣기 · 나누기는 새 ID를 받는다.
- 블록 표기: `p` `h1`–`h3` `ul` `ol` `li` · `ul[data-type=taskList] > li[data-type=taskItem][data-checked]` · `details.nb-toggle[open][data-level] > summary + div[data-type=detailsContent]` · `blockquote` · `div[data-type=callout][data-icon][data-color]` · `hr` · `pre > code` · `div.tableWrapper > table`(셀 `data-bg`, `colwidth`) · `figure.img[data-align][data-width]` · `a.file[data-name][data-fid]` · `a.bookmark[data-type=bookmark]` · `iframe.embed` / `video` / `audio` · `div[data-type=columns] > div[data-type=column][data-w]` · `nav[data-type=toc]` · `div[data-type=raw][data-html]`
- 인라인: `strong` `em` `u` `s` `code` `a[href]` · `span[data-color]`(글자색) · `mark[data-bg]`(배경) · `span.mention[data-id]` · `a[data-type=pageLink][data-item]` · `span.datechip[data-date][data-end]`. 색은 이름(gray · brown · orange · yellow · green · blue · purple · pink · red)으로만 저장한다.
- 2 · 3차에 더한 표기: `pre > code.language-<언어>` · `span[data-type=math][data-tex]` · `div[data-type=mathBlock][data-tex]` · `div[data-type=button][data-label][data-action][data-tpl|data-href]` · `div[data-type=synced][data-item][data-block]`(참조만) · `div[data-type=itemList][data-kind][data-proj][data-state][data-mine][data-limit]`(조건만) · 날짜의 `data-remind`(0 · 1 · 2 · 7일 전) `data-by`(설정한 사번).
- 블록 댓글은 본문이 아니라 글의 `comments`에 `block`(블록 ID) · `quote`(그때의 앞 80자) · `resolved`를 더해 저장한다. 템플릿은 `meta:settings.templates`.
- 모르는 블록(`data-type`이 스키마에 없는 것, 더 새 버전이 쓴 것)은 지우지 않고 `raw` 블록으로 감싸 그대로 보관하며 화면에는 편집할 수 없는 상자로 보인다.

## 기존 본문(v1)과 되돌리기

- v1 본문은 누가 수정해서 저장하기 전까지 손대지 않는다. 읽기 화면도 기존 방식 그대로다.
- 수정을 누르면 `upgrade()`가 v1 표기(`div.todo` · `div.toggle` · `div.callout` · `span.datechip` · `a.file` · `a.bookmark` · `figure.img` · `iframe.embed` · 인라인 색)를 v2 블록으로 읽는다. 아무것도 바꾸지 않고 취소하면 저장된 본문은 한 글자도 달라지지 않는다.
- 처음 v2로 저장할 때 원래 본문을 `bodyV1`에 한 번 보관한다.
- 끄는 방법: 브라우저에서 `localStorage['aidc-editor']='v1'`, 또는 `meta:settings.editor='v1'`(전체). 이미 v2로 저장된 글은 계속 새 편집기로 연다(구 편집기가 새 블록을 지우지 않게 하려는 것).
- 구 버전 페이지는 MIN_CLIENT 4 때문에 새로고침 안내를 받는다.
- `r5cdb8f30-5b91-4ec8-9d7b-038aeca21001`(Test 글)은 다른 실험(`research-editor-trial.js`)용이라 새 편집기를 쓰지 않는다.

## 저장 모델 (지시서 19절과의 대응)

기존 규칙을 유지한다: 수정 → 서버 잠금 → 저장 / 취소. 저장을 눌러야 다른 멤버에게 보인다. 입력을 멈추면 0.9초 뒤 이 브라우저에 초안을 보관하고(`aidc-recovery:<사번>`) 머리줄에 "초안 보관됨"을 표시하며, 저장하지 않고 창을 닫으면 다음 접속 때 "[복구 초안]"으로 돌아온다. 올리는 중인 파일이 있으면 저장하지 않는다. 토글을 접고 펴는 것은 수정으로 치지 않는다.

- **나갈 때 묻지 않는다** (소유자 결정, 2026-11-18): 수정 중인 글을 닫거나 다른 곳으로 가면 저장하고 토스트에 ‘되돌리기’를 준다. 새 글은 초안이 된다(제목이 없으면 “제목 없음”). 바뀐 것이 없으면 잠금만 바로 돌려준다. Ctrl+S는 저장.
- **읽기 화면의 작은 저장**: 할 일 체크와 버튼 블록은 수정 모드에 들어가지 않고 본문 HTML의 해당 부분만 고쳐 바로 저장한다(`nbQuickEdit`). 다른 사람이 수정 중이면 하지 않는다.
- **버전 기록**: 게시된 글의 제목 · 본문이 저장될 때마다 Worker가 `versions` 테이블에 한 판을 남긴다(요청당 하나, 같은 사람이 1분 안에 이어 저장한 것은 한 판, 첫 변경 때는 그 전 내용도 `base`로 보관, 글당 100판, 글이 완전히 지워지면 함께 삭제). 초안은 남기지 않는다. `GET /api/versions?item=` · `GET /api/version?id=`.
- **함께 수정**: 다른 멤버가 수정 중인 글에서 ‘함께 수정’을 누르면 그 편집에 참여한다(`/api/lock` action `join` → `co_locks`). 먼저 수정하던 화면이 잠금 목록에서 참여자를 보고 자기 문서를 Yjs 공유 문서로 바꿔 보내고(`nbUpgrade`), 이후 변경과 커서는 `/api/live` 소켓으로 오간다(Worker는 `ydocs`에 합쳐 두고 중계만 한다). 공유 문서는 **수정하는 동안만** 있다: 마지막 사람이 나가면 지워지고, 저장된 `body`가 다시 유일한 원본이다. 저장은 각자 기존 방식대로 하고(본문은 공유 문서에서 만든 HTML), 먼저 저장한 사람의 본문이 나머지 사람의 저장 기준이 된다(`sharedApply`의 `_co` 처리). 취소는 자기 제목 · 속성 변경만 버린다 — 본문에 친 글은 남아 있는 사람의 문서에 남는다. 혼자 수정할 때는 이 코드가 전혀 돌지 않는다. 첫 편집기(Test 글, `aidc-editor=v1`)로 수정 중인 글은 참여 요청을 거절한다.

## 지시서 항목별 상태

완료 = 구현하고 자동 검사로 확인. 부분 = 일부만 구현(무엇이 빠졌는지 적음). 미구현 = 이번에 만들지 않음. 차단 = 서버 · 외부 서비스 · 결정이 있어야 가능.
실제 운영 사이트는 빌드 환경에서 접속할 수 없어 모든 확인은 로컬 개발 서버에서 했다. 실제 한글 IME · 터치 · 화면 낭독기 · Safari / Firefox 수동 검수는 하지 못했다.
